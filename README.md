# Ola Ball

**Call the shots. Learn football by coaching.**

Ola Ball is a native iOS game for people who watch sports with someone they love but never learned the rules. You're the coach. A drive unfolds one play at a time, you pick the call (run, pass, punt, kick), and the rules of football get explained only at the moment you need them to make a decision. No quizzes. No lessons. Just a scoreboard, a Playbook that fills in as you go, and a reason to play one more game.

## How it plays

1. Pick a team (all fictional, no real franchises or players).
2. Each quarter you get one drive and the other team gets one. Four quarters, overtime if tied.
3. On every play, choose **Run**, **Short Pass**, or **Deep Pass**. On 4th down, choose **Punt**, **Field Goal**, or go for it.
4. **Coach's Tips** appear the first time a situation shows up (your first 3rd down, your first time in field-goal range, the first time you're down by 3 in the 4th). Each one becomes a card in your **Playbook**.
5. Earn XP, climb from Rookie Coach to Hall of Famer, keep a day streak.

## Project layout

```
OlaBall/
  App/         entry point, root routing
  Models/      Team, Situation, PlayCall, Play, DriveSummary
  Engine/      PlaySimulator (odds), RulesEngine (downs & scoring), OpponentCoach (AI), Narrator (play-by-play), SeededRNG
  Content/     Concepts (the Playbook) and TipDirector (when each tip fires)
  Game/        GameSession (one game's state machine)
  Store/       ProgressStore (local-only persistence)
  Views/       SwiftUI screens
OlaBallTests/  Swift Testing unit tests for the engine, tips, and a full simulated game
scripts/       make_icon.swift renders the App Store icon
```

The engine is pure and seedable. `GameSession` is the only stateful object during a game and the views just render it.

## Building

The Xcode project is generated from `project.yml` with [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```bash
brew install xcodegen
xcodegen generate
open OlaBall.xcodeproj
```

Run tests with ⌘U or:

```bash
xcodebuild test -project OlaBall.xcodeproj -scheme OlaBall -destination 'platform=iOS Simulator,name=iPhone 16 Pro'
```

Requires Xcode 16+ and iOS 17+.

## App Store readiness

The previous version of this app was rejected over account handling. This version is designed so those guidelines don't apply:

- **No accounts, no sign-in, no network.** Nothing leaves the device, so Guideline 5.1.1(v) (account deletion) and 4.8 (Sign in with Apple) are moot.
- **Privacy manifest included** (`OlaBall/PrivacyInfo.xcprivacy`): no tracking, no collected data types, UserDefaults declared with reason CA92.1.
- **Local data is user-erasable** via "Reset progress" on the home screen.
- **No usage-description permissions** requested. No camera, mic, photos, location, or notifications.
- **No real teams, leagues, players, or logos.** All team names are fictional. Nothing references the NFL or any trademark.
- **Encryption export flag set** (`ITSAppUsesNonExemptEncryption = false`).
- **1024×1024 icon** with no alpha, generated by `scripts/make_icon.swift`.
- **Real functionality**, not a thin wrapper or placeholder content (Guideline 4.2).

Still needed in App Store Connect before submitting: a privacy policy URL (see `docs/privacy-policy.md`, which is accurate for this build and can be hosted on GitHub Pages), a support URL, screenshots, and the age rating questionnaire (no objectionable content, no gambling, no user-generated content).
