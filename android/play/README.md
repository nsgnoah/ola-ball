# Play Store art

Everything Google Play needs from the design side, and where each file goes in the Play Console
(**Grow > Store presence > Main store listing**, unless noted). The launcher icon itself lives in
the app, not here: `app/src/main/res/drawable/ic_launcher_{background,foreground,monochrome}.xml`
and `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`, drawn from the same geometry as the iOS
icon (`OlaBallTests/AppIconTests.swift`).

| File | Play Console slot | Spec | Source |
|---|---|---|---|
| `icon-512.png` | Main store listing > Graphics > **App icon** | 512x512 32-bit PNG (RGBA, every pixel opaque), under 1 MB. Play applies its own rounded corners and shadow, so the square art ships as is. | Downscaled from the iOS icon, `OlaBall/Resources/Assets.xcassets/AppIcon.appiconset/icon.png` |
| `feature-graphic.png` | Main store listing > Graphics > **Feature graphic** | 1024x500 PNG or JPEG, no alpha, under 15 MB. Shown above the listing and in promotions; keep text inside the middle so it survives cropping. | Rendered from `feature-graphic.svg` |
| `feature-graphic.svg` | Not uploaded; the editable source | The game's violet-night backdrop with sunburst rays and the halftone band (`GameBackground`), the wordmark's two stacked chips with the VS badge (`Wordmark` in `Views/HUD.swift`) and the line "Trivia for two" in Rockwell. | Generated by `icon_vectors.py` from the Swift geometry |
| `screenshots/phone/*.png` | Main store listing > Graphics > **Phone screenshots**, in file-name order | Eight 1080x1920 24-bit PNGs (no alpha). Play rejects any screenshot more than twice as tall as it is wide, so these come from the emulator booted at 9:16 (`emulator -avd spinola_phone -skin 1080x1920`, then `../scripts/store_shots.sh phone-9x16`), converted with `pngtool.py opaque`. Three or more 1080x1920 portrait shots make a game eligible for Play's large recommendation formats | The instrumented play-through, `app/src/androidTest/.../PlayThroughTest.kt` |
| `listing/en-US/` | Main store listing > **App name**, **Short description**, **Full description**; release notes for the first release | 30, 80 and 4000 characters; checked. The folder follows the `fastlane supply` layout so a later automated upload can read it | Written for this listing |

Not produced: 7-inch and 10-inch tablet screenshots (optional). The tablet layout was checked by eye
on a 1600x2560 emulator, but screen capture at that size times out on this Mac's software GPU.

## Regenerating the PNGs

Only macOS tools are used (no Pillow, no ImageMagick):

```bash
./android/play/render.sh
```

- `icon-512.png` is `sips -z 512 512` of the iOS icon, then `pngtool.py rgba` adds an opaque alpha channel, because Play asks for a 32-bit PNG.
- `feature-graphic.png` is rendered by Quick Look (`qlmanage -t -s 1024`). Quick Look lays an SVG out on a 750pt page and crops anything wider, then pads its thumbnail to a 1024x1024 square with the content at the top left. The script therefore feeds it a copy of the SVG with its root sized 750x366 (the `viewBox` keeps the 1024x500 geometry), crops the 1024x500 corner back out with `pngtool.py` and drops the alpha channel Quick Look always writes. `pngtool.py` refuses if any pixel is not opaque, so a mis-crop fails loudly instead of shipping a transparent edge.
- The SVG names `Rockwell` first and `American Typewriter` as the fallback; Rockwell ships with macOS in `/System/Library/Fonts/Supplemental`, so the render matches the app's type. Rendering on a machine without Rockwell would change the lettering; check the PNG.

After changing the icon in Swift, re-run `AppIconTests` on iOS to refresh `icon.png`, mirror the
new numbers in `icon_vectors.py` (it holds the same geometry as `AppIconArt`, mapped onto the
108dp adaptive-icon canvas at 76dp per icon side so the wheel and pointer stay inside the 66dp
safe circle) and run it to rewrite the three `ic_launcher_*.xml` vectors and `feature-graphic.svg`,
then `render.sh` for the PNGs. `icon_vectors.py` also writes an `icon-preview.svg` of the adaptive
icon under a circular mask, with the monochrome layer beside it, for a look before a device does.

## Colours

All from `Theme` (identical on both platforms): his `#2F56BF`, hers `#D6406F`, ink `#1D1A33`,
gold `#EDB240`, goldDeep `#B97F0C`, night `#1A1B4B`, nightDeep `#0E0F2E`, violet `#4F3DB0`, cream
`#FFF3D9`. The backdrop is violet mixed 30 percent toward night, `#3F3392`, the same value as
`stage_violet` in `app/src/main/res/values/colors.xml`.
